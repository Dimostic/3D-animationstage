Prompt Writing Guide

Quick Formula
action + target + modifiers

e.g. spin the red circle slowly clockwise

Targeting Objects
by color + typethe red circle, blue squares
by nameany part of the object's name
by positiontop, bottom-left, center
all of a typeall circles, all shapes
pronounsit, them, the object (refers to last target)

Multi-Step Sequences

Use then, next, or after that to chain actions. Use it to refer to the previous target.

create a red circle, then make it bounce twice, then spin it clockwise forever

fade in the star slowly. then move it right 300px. after that make it pulse

create a blue square at the top-left, then make it drop, then slide it right 400px

Joints, Deform & Flex

Joint assembly is the main character-animation path. Use Body Stencil for one full human image, Smart Cut for traced single-image parts, Guided Assembly / Joint Assembly for separated parts, and Image Deform when you need to warp one flat image directly.

jointsHinge-style joints for bending shapes and rotating cutout parts
which workflowAsk AI things like which character workflow should I use for one full image? to get the right setup path before you start.
face rigFor one selected face image, use show me the practical face rig workflow to get fit/apply/check/preview/record guidance before animating dialogue.
guided assemblyGuided joint setup for separated body parts. For one full image, use Body Stencil or Smart Cut first.
joint assemblyAssemble body-part images into articulated characters. 6 presets: Human Front, Human Side, Quadruped, Bird, Spider, Fish. Auto-detects parts by name.
joint movementsPre-built movement and pose-hold presets such as Wave, Walk / March, Strongman Flex, Combat Idle, and Celebrate. Applied per-part as timeline bars.
character posesSave, load, blend, copy across, mirror, randomize, ragdoll, and reset assembled-character poses from the Joints section. Human Front built-ins here are static poses; animated versions also exist in Movements.
body tagsPersistent character landmarks such as eyes, nose, sternum, waist, fingertips, and toes. Auto-tags assembled presets, supports custom points, and keeps the points relative to the tagged body part as the character moves.
copy acrossSelect source joints on one side, then click Copy Across to duplicate their mirrored angles onto the opposite side without changing the source.
tune jointsVisually adjust anchors (blue diamonds) and pivots (orange circles) after assembly. Save as Template for reuse.
train from stageCapture manually tuned joint positions as training data. Future assemblies auto-apply trained values.
body stencilFit a ready-made body map to one full image, then cut and assemble parts automatically.
smart cutTrace & cut body parts from a single image with edge-snapping, or auto-trace silhouette-based preset parts on supported human templates, then auto-assemble with joints.
image deformWarp one flat image with Deform Pins, Influence Bones, and mesh deformation. Best for squash, stretch, and localized warping.
flex toolArc bending with anchor points. Preserve Texture bends the rendered surface so images, patterns, and gradients keep their skin while curving.
templatesSave joint configurations as reusable templates; load onto other objects

These tools are used via the Properties panel (select an object → Image Tools / Joints / Flex sections). AI can animate objects that already have joints or image-deform controls applied, and you can ask Teach Me for workflow advice if you are unsure which path fits.

copy propertiesRight-click object → Copy Properties. Copies readable text + JSON payload, including Stage Angle, Stage ±180, From Down, joint angle, X/Y tilt, pin target, parent joint, pin offset, pin rotation mode, and any Body Tags stored on that object. Paste as Clone creates an exact duplicate on stage.
copy all propertiesRight-click empty stage → Copy All Properties. Exports a 49-column tab-separated table of all objects, including pin target/joint/rotation fields, joint details, transformed corners, Stage Angle, Stage ±180, From Down, and Body Tags for spreadsheet audits.
pin to jointUse the Object Attachment section: choose a Parent Object, optionally choose a Parent Joint, then set Rotation Mode to Align with Parent or Joint if the child should follow the parent joint angle.
assets libraryUse the Assets toolbar button to browse, preview, upload, search, delete, and import filesystem-backed library items. Right-click any object to Save to Assets Library.
search assetsAI mode can list and search library items, for example list assets, search assets for torso, or import torso on stage.
pose armature skinIn Pose Armature, Place Overlay adds a temporary alignment image over the rig, while Sample Selected bakes the selected image into the armature parts as the actual skin.
pose armature templateAfter skinning a rig, use Save Template to store that armature look. On a similar front, side, or generic rig, choose the saved entry and click Apply to reuse it.
dummy transparentInside Pose Armature, use Transparent to show unsampled dummy rigs as low-fill overlays with visible borders, or Solid to switch them back to block shapes.
front dummy armatureUse Joints → Front Dummy or the same button inside Pose Armature to create a reusable front-view rig with torso, head/neck, left/right arms, and left/right legs before using Sample Selected or Place Overlay.
side dummy armatureUse Joints → Side Dummy or the same button inside Pose Armature to create a reusable side-view rig with torso, head/neck, one side arm, and front/back legs before using Sample Selected or Place Overlay.
side 2 armsUse Side 2 Arms when a profile character needs both a Front Arm and a Back Arm. If one profile arm or leg is hidden in the source image, the sampler can reuse the visible counterpart as fallback.
down 0In Transform, Down → 0° rotates the selected object so its visible direction points straight down, then bakes that as the new 0° baseline. Best for front-facing limbs.
reset jointsIn the left-panel Joints section, Reset All 0° returns the selected rig's internal and assembly joints back to zero without deleting them.
clear timelineThe timeline trash button Clear Timeline removes every animation bar after a confirmation prompt.
measure toolShows pixel distances from objects to stage edges and gaps between nearby objects on hover.
app searchCtrl+/ (Cmd+/) — Spotlight-style finder for all tools, buttons, sections, tabs, properties, and inputs.
